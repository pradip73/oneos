Welcome to OneOS

One computer that runs Linux, Windows and Android software. Here is what works, and — just as important — what does not.

Installing programs

🐧

Linux

Open Programs in the Control Panel, or double-click a .deb file.

🪟

Windows

Double-click any .exe. Each program gets its own sealed workspace.

🤖

Android

Double-click an .apk. The first one sets Android up — about 700 MB, once.

Anything you install appears on the desktop and in the menu by itself.

What will not work

Please read this before you rely on OneOS

Android apps that check for Google Play — banking apps, Netflix and most paid streaming — will refuse to run. This is not a bug and it cannot be fixed here.

Windows software needing anti-cheat or hardware drivers — competitive online games, antivirus, VPN clients with kernel drivers — will not run either.

Windows programs can still misbehave. They are sealed off from your files, but a program you did not trust is still a program you should not run.

Two things worth knowing

This desktop is temporary

OneOS currently borrows the KDE Plasma desktop while its own is built. Everything you learn here still applies.

It is early

Version 0.2. Things will break. Keep a backup of anything you cannot lose.
